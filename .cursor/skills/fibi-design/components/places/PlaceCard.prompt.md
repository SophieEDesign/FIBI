The saved-place card. Use `vertical` in grids, `row` in lists and map drawers.

```jsx
<PlaceCard name="Time Out Market" location="Lisbon, Portugal" source="tiktok"
  note="Go early — the seafood counter gets busy." tags={["Food","Lisbon"]} />
```

With no `image` it falls back to the soft brand wash and a pin glyph — never a grey box.
