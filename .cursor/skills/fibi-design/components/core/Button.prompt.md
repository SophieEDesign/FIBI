Pill-shaped action button; the default control for anything the user commits to.

```jsx
<Button variant="primary" size="md" iconLeft={<Icon name="plus" />}>Save place</Button>
```

Variants: `primary` (sky), `gradient` (brand sweep — hero/marketing CTAs only, once per screen), `secondary` (outlined), `ghost`, `soft` (tinted), `danger`. Sizes sm/md/lg map to the 32/40/48px control heights. Pass `href` to render an anchor.
